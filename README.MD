# Narayan Soni Portfolio

A sleek, interactive 3D portfolio showcasing my skills in full‑stack development, cloud engineering, and data analytics.

## Quick Start
1. **Install dependencies**: `npm install`
2. **Run locally**: `npm run dev` → http://localhost:5173
3. **Build for production**: `npm run build`

## Features
- **3D Animations** with React Three Fiber
- **Responsive** design powered by Tailwind CSS
- **Smooth transitions** via Framer Motion
- **Contact form** integrated with EmailJS

## Deployment
Host the contents of the `dist/` folder on Vercel, Netlify, or GitHub Pages.
